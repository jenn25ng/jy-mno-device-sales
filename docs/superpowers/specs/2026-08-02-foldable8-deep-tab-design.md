# 폴더블8 심화 분석 탭 설계 (모델 중심)

- 작성일: 2026-08-02
- 대상: `frontend/index.html` `tabFold8`, `backend/aggregate.py` `build_sku`, `backend/data.py` `sku_rows`, `backend/main.py` `/api/sku`
- 관련: [단말별 분석 탭](2026-07-22-device-analysis-tab-design.md)의 신제품(폴더블8) 특화판

## 배경 / 목적

기존 폴더블8 분석 탭은 "모델·용량 구성"(KPI + 모델막대 + 용량박스 + SKU×본부 표)만 보여준다.
현업 요청: 신제품 출시 맥락에서 **① 일자별 판매 추이**와 **② 어느 본부에서 인기 있나**를
신제품 내부 관점(플립/폴드/울트라)으로 볼 수 있어야 함.

단말별 분석 탭은 이미 폴더블8을 "단말군→본부" 관점으로 커버하므로, 이 탭은 그와 겹치지 않게
**신제품 내부(모델·용량) 관점**에 집중한다.

## 확정 요구사항 (브레인스토밍)

1. **분석 단위 = 모델 중심** (플립 / 폴드 / 울트라). 용량은 보조.
2. **본부 인기 = 모델×본부 히트맵** (본부 행 × 모델 열).
3. **일자 추이 = 모델별 3라인(판매량)**.

## 접근안

- **A안 (채택) — 증축**: 현 구조 유지 + 신규 2섹션(일자 3라인, 모델×본부 히트맵) 삽입. 기존 재활용, 백엔드 소폭.
- B안 — 단말별 탭 완전 복제: 무겁고 단말별 탭과 중복.
- C안 — 최소(3라인만): "어디서 인기" 미충족.

| # | 섹션 | 내용 | 상태 |
|---|------|------|------|

| 1 | KPI | 총 판매 + 플립/폴드/울트라 3장(순위·비중·베스트용량) | 유지 |

## 데이터 계약 (build_sku 확장)

`build_sku` 반환 dict에 2개 필드 추가 (기존 `total/top_sku/top_hq/by_sku/detail` 유지):

- `models`: `[{name, count, share}]` — 모델(플립/폴드/울트라) 집계, 판매순. (프론트 계산 대체용, 선택)
- `daily`: `[{date, "플립", "폴드", "울트라"}]` — 일자별 모델 판매량. **비영업일 제외**.
- `model_hq`: `{모델: {본부: 건수}}` — 히트맵용 모델×본부.

### 모델 분류 규칙 (서버·프론트 동일)

`series`(raw_series_nm) 기준, **울트라 먼저 판정**:
- `울트라` 포함 → "울트라"
- `플립` 포함 → "플립"
- `폴드` 포함 → "폴드"
- 그 외 → "기타"

### 워킹데이(영업일) 정합

- `daily`는 다른 일별 추이 차트와 동일하게 **비영업일 제외**.
- 영업일 집합은 `main.py`가 캐시 df(전체 판매)로 해당 기간 op-day를 구해(`aggregate._operating_days`) `build_sku`에 `op_days` 인자로 전달. build_sku는 `daily` 생성 시 이 집합으로 필터.
- `sku_rows` 반환 컬럼에 `exec_dt` 추가(`_SKU_DIMS`).

## 프론트 (tabFold8)

- **일자별 3라인**: 기존 `hqLineChart`(단말별 탭) 패턴 재사용 — 계열=모델 3개, 값=판매량, index 툴팁, 범례 토글(`STATE.fold8Hidden`).
- **모델×본부 히트맵**: 매트릭스 탭 `heat2` 틴트 패턴 재사용 — 행=본부(HQS 순), 열=모델 3, 셀=건수+본부내비중%, 배경=모델 색 color-mix(강도∝본부내비중).
- 모델 색: 플립 `#E24B92` / 폴드 `#C13C7C` / 울트라 `#8E3C6B` (KPI·막대와 동일).
